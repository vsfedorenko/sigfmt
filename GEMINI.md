# GEMINI.md

Этот файл содержит контекст и руководство для AI-ассистентов (включая Gemini) при работе с кодом в данном репозитории.

## Обзор проекта

Это плагин-линтер для `golangci-lint` под названием `funcwrap`.
Основная цель: проверка и улучшение форматирования сигнатур функций в Go.

Линтер анализирует:
- Объявления функций и методов.
- Функциональные литералы.
- Методы интерфейсов.
- Поля структур с типом `func`.

## Логика работы

1.  **Collapse:** Если сигнатура (параметры + возвращаемые значения) помещается в одну строку (с учетом `MaxLineLen`), линтер предлагает схлопнуть её.
2.  **Reformat (Packing):**
    - Для **методов интерфейсов** и **полей структур**: Линтер пытается упаковать параметры компактнее (несколько на строке), если они не помещаются в одну строку.
    - Для **обычных функций**: Линтер сохраняет существующее многострочное форматирование, если оно уже есть и сигнатура не помещается в одну строку (чтобы не портить ручное форматирование).

## Архитектура

-   `linter.go`: Основная реализация.
    -   `PluginLineWrap`: структура плагина.
    -   `signatureInfo`: структура для хранения информации о найденной сигнатуре.
    -   `checkSignature`: определяет действие (`collapse`, `reformat` или ничего).
    -   `buildReformattedSignature` / `renderFieldListGrouped`: логика генерации нового текста.
-   `linter_test.go`: Запуск тестов через `analysistest`.

## Тестирование

Тестовые данные находятся в `testdata/src/`:
-   `features/`: Тесты функциональности (различные конструкции языка).
-   `limits/`: Тесты граничных значений (80, 100, 120, 140, 160 символов).

Запуск тестов:
```bash
go test ./...
```

## Конфигурация

Настройки передаются через map в метод `New`.
Основная настройка: `max-line-len` (int, по умолчанию 120).

## Особенности реализации

-   Использует `go/ast` и `go/token`.
-   Не требует информации о типах (`register.LoadModeSyntax`).
-   Собственная логика рендеринга AST узлов (`renderNode`, `renderFieldList`) для точного контроля формата.
-   Обработка Generic-ов (type parameters).
