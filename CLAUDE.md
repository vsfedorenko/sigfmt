# CLAUDE.md

**Context & Guidelines for AI Assistants**

## Project: `sigfmt`
- **Type:** `golangci-lint` plugin (Go 1.25+).
- **Goal:** Check/format function signatures (declarations, methods, literals, interfaces, struct fields).

## Core Logic
1.  **Collapse:** If multi-line signature fits `max-line-len` -> collapse to one line.
    - *Diag:* "Multi-line signature can be collapsed to one line"
2.  **Reformat (Pack):** If signature exceeds one line:
    - **Funcs:** Conservative (preserve grouping).
    - **Interfaces/Structs:** Aggressive packing (multiple params/line).
    - *Diag:* "Signature can be reformatted more compactly"

## Architecture
- **`linter.go`**: AST-based, syntax-only (fast). Custom rendering (no `go/printer`).
- **`linter_test.go`**: `analysistest` framework. Tests use `// want "msg"` and `.golden` files.

## Configuration
Passed to `New()`. Defaults: `max-line-len: 120`, `tab-width: 8`, `pack-struct-fields: true`, `pack-interface-methods: true`.

## Testing & Workflow
- **Mocks:** interface doubles are generated by mockery (`.mockery.yml`,
  testify template, in-package `mocks_test.go`). Run `make mocks` after
  changing an interface; mocks are committed. Assertions use testify
  (`assert`/`require`).
- **Dir:** `testdata/src/{features,limits,settings}`.
- **Run:** `make test` (or `go test ./...`).
- **Update Diagnostics:**
    1. Modify `linter.go` constants.
    2. Update test files (`.go`) and expectations (`.golden`).
    3. Run `make test-update-golden`.
- **CI/CD:** GitHub Actions for tests (`ci.yml`), releases (`release.yml`), dependencies (`dependabot.yml`).

## Guidelines
1.  **Tests:** Run `make test` after changes.
2.  **Golden Files:** Sync `.go` comments and `.golden` content when changing logic.
3.  **Style:** English comments, constants for strings.
4.  **Perf:** Minimize allocations, avoid type loading.
